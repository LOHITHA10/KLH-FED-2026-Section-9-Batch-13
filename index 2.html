Introduction & Objective

One register, four operations

A shift register is a sequential circuit that stores and shifts binary data. A universal shift register performs all four operations in a single circuit, chosen by two mode-select lines.

Introduction

  • Combines combinational logic (4:1 MUX from AND, OR, NOT gates) with memory (D flip-flops).
  • The MUX decides what to store; the flip-flop remembers it on the clock edge.
  • Needed for serial-to-parallel conversion, temporary storage, and multiply/divide by 2 using shifts.

Objectives

  • Design a 4-bit universal shift register using logic gates and D flip-flops.
  • Understand how a 4:1 MUX selects the operating mode.
  • Implement hold, shift right, shift left and parallel load.
  • Verify the design with a truth table and Logisim simulation.

Theory & Logic Circuit

Each stage: one MUX + one D flip-flop

Four identical stages share the select lines S1, S0 and a common clock. The MUX output Y feeds the D input, so Q(next) = D = Y on every rising clock edge.

Gates & components

  • 4 × D flip-flops (IC 7474) — 1 bit each.
  • 4 × 4:1 MUX (IC 74153, or AND-OR gates).
  • AND, OR, NOT (ICs 7408, 7432, 7404) — per MUX: 4 × 3-input AND, 1 × 4-input OR, NOT gates for S1′ and S0′ shared by all stages.
  • CLK and CLR common to all flip-flops.
Y = S1′S0′·I0 + S1′S0·I1 + S1S0′·I2 + S1S0·I3

K-map: the four select minterms are isolated, so this SOP is already minimal.

Implementation & working

Sample schematic view. Click the image to replace it with your own Logisim screenshot.

How the circuit is built

  • Inputs: S1, S0 (mode), CLK, CLR, parallel data P3–P0, serial inputs SRI and SLI.
  • Each stage has a 4:1 MUX (AND-OR gates, shared NOT gates for S1′ and S0′) whose output drives a D flip-flop.
  • Outputs Q3–Q0 are shown on LEDs / output pins.

How it works

  • 00 Hold: each flip-flop re-loads its own Q.
  • 01 Shift right: Qi ← Qi+1, and Q3 ← SRI.
  • 10 Shift left: Qi ← Qi−1, and Q0 ← SLI.
  • 11 Parallel load: Qi ← Pi.
  • All changes happen only on the rising clock edge.

06 / 06
Conclusion & Applications

Logic that decides, memory that remembers

Outcome
  • Designed and simulated a 4-bit universal shift register with hold, shift right, shift left and parallel load.
  • The MUX chooses the next value and the flip-flop stores it.
  • K-map confirmed the MUX logic is minimal, with shared inverters.
  • All four test steps matched the expected outputs.
Applications
  • Microprocessors: temporary storage and shifting.
  • Communication: serial/parallel conversion (UART).
  • Arithmetic: multiply / divide by 2 via shifts.
  • Counters: ring and Johnson counters.
  • Memory: delay lines and FIFO.
Possible Improvements
  • Extend to 8 / 16 / 32 bits by cascading stages.
  • Add arithmetic shift and rotate modes.
  • Use the single IC 74194 for a compact, low-power build.
  • Build it on a breadboard (7474, 74153, 7408, 7432) and lead into an ALU design.
